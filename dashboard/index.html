Limitations

  • Fixed input fixtures, not issue forecasting.
  • Fixture-level heuristic scores, not production measurements.
  • Baseline representation, not full production replay.
  • LeWorldModel-inspired expectation trace observer, not an implementation of the LeWorldModel paper.
  • No claim of runtime superiority, planning gains, or production recovery.
  • Maintainer-rated scoring has not replaced the heuristic rubric yet.
